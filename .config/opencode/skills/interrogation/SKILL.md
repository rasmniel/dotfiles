---
name: interrogation
description: Interrogate me relentlessly about the current plan or design until reaching shared understanding. Use when critically analyzing a plan, creating a larger plan from scratch, or asked to perform interrogation.
---

Interview me relentlessly about every aspect of the current plan until we reach a shared understanding.
Walk down each branch of the design tree, resolving dependencies between decisions one-by-one.

For each question, suggest your recommended answer.
When providing multiple suggestions, label them with appropriate identifiers, e.g. indices.

If a question can be answered by exploring the codebase, do so instead.

Ask only one single question at a time to avoid overwhelming the user.
Ask questions inline as part of the output text.
Do not use any question-related tools during interrogation.
